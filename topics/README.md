# Shared topics

Reusable examples live here by subject. C++, Java and Python implementations of the
same subject share a directory; their language is metadata in the catalogue.
The topic-only printable version is [doc/topics.pdf](../doc/topics.pdf).

| Subject | Editable sources |
| --- | --- |
| Arrays, collections and C++ container calls | `collections/` |
| Graph traversal and grids | `graphs/` |
| Binary search, C++ sorting and lambdas | `search/` |
| C++ strings and parsing | `strings/` |
| Runtime modular arithmetic, inverses and congruences | `modular_arithmetic/` |
| Kadane | `dynamic_programming/` |
| Bit operations | `bitwise/` |
| Base conversion | `numeral_systems/` |
| Data structures | [KACTL data-structures](../vendor/kactl/content/data-structures/) |
| Mathematics | [KACTL math](../vendor/kactl/content/math/) |
| Numerical algorithms | [KACTL numerical](../vendor/kactl/content/numerical/) |
| Modular arithmetic and number theory | [KACTL number-theory](../vendor/kactl/content/number-theory/) |
| Combinatorics | [KACTL combinatorial](../vendor/kactl/content/combinatorial/) |
| Graph algorithms | [KACTL graph](../vendor/kactl/content/graph/) |
| Geometry | [KACTL geometry](../vendor/kactl/content/geometry/) |
| Strings | [KACTL strings](../vendor/kactl/content/strings/) |
| Search, DP and optimization | [KACTL various](../vendor/kactl/content/various/) |

KACTL's directory structure is preserved so relative header dependencies continue
to work. Both sets of sources are integrated into the same subject sections in
the PDFs. Only starter templates live in the top-level language directories.
